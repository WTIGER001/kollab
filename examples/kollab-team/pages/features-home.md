# Features

Use this project as a task-oriented handbook. The reference sections explain the controls; the demonstration section places those controls inside real documentation. Start with a page in read mode, then select **Edit** to inspect how its blocks are configured.

## A useful first session

1. Open the [Rich authoring demonstration](page:authoring-demo).
2. Expand a details block and switch tabs while reading.
3. Enter Edit mode, change a status label, and tick a task.
4. Open the [Architecture walkthrough](page:architecture) to inspect a Mermaid diagram.
5. Visit the [Training materials](page:training-materials) page and download the PowerPoint.

## Capability map

| Need | Kollab workflow | Demonstration |
