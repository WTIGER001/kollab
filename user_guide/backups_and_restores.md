# Backups and Azure Storage

> **Availability: not ready for production use.**

Kollab does not currently provide a real Azure Blob Storage or Azure Backup Vault integration. The administration screen and related code are prototypes with mock storage and recovery data, so do not enter Azure credentials or rely on it for recovery.

Use your database provider and infrastructure platform's established backup tooling until a future Kollab release provides a tested, documented backup integration.
