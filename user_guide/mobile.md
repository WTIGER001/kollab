# Using Kollab on a phone

## Move around

Tap the menu icon in the top bar to open workspace navigation. The drawer opens over the page, leaving your reading position in place. Select a page or space to navigate and close it. You can also use its close button, tap outside it, or press **Escape** with a keyboard.

While viewing **Server Settings**, the same button opens admin navigation instead of the authoring page tree. Each settings section has its own page. **Back to workspace** returns to recent pages. See [Server settings](server_settings.md).

Tap the search icon to open the search page. **⌘P** on Mac or **Ctrl+P** on other keyboards also opens search on a narrow screen. Your account menu contains theme switching, help, favorites, recent pages, tasks, notifications, and available administration options.

## Read and edit pages

Use **Edit** to start editing and **Done** to finish. Long page titles wrap so you can read them without sliding the page sideways. On phones, the **Page actions** menu includes version history, analytics, and watching a page, keeping the main header compact. Actions that modify a page remain unavailable when you only have read access.

The formatting toolbar stays on one row while editing. Swipe it sideways to reach more formatting tools and macros. This scrolls the toolbar, not the page. Labels and form text remain readable on small screens, and the layout follows the available browser height.

Comments open over the page on phones instead of squeezing the editor into a narrow column. Close the comments panel to return to the full editor.

## Appearance

Light and dark modes work with Default, Workbench, Editorial, and Neobrutalism presets. Form fields stack where needed, and theme choices use compact preview cards. Large data tables can scroll within their own region while navigation and page actions stay within the screen.
