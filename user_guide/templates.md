# Templates

Templates allow you to create standardized documents and reusable block snippets across your workspaces. They help teams maintain consistency and save time when creating recurring content like meeting notes, product specs, or project kickoffs.

## Page Templates

Page Templates provide a complete starting point for a new document. When you create a new document using a Page Template, the document is prepopulated with structure, boilerplate text, and placeholders.

**How to Use Page Templates:**
1. Click **Create page** in the sidebar.
2. The create-page wizard opens.
3. Browse the available "Page Templates".
4. Choose a template card or **Blank Page**, continue to the page details, enter the title and destination, and create the page.

## Block Snippets

Block Snippets are smaller, reusable chunks of content that you can insert into any existing document. This is ideal for recurring sections, such as a standardized status update table or a specific callout panel format.

**How to Use Block Snippets:**
1. While editing a document, type `/` to open the slash command menu.
2. Search for your template's name (or browse the **Snippets** section).
3. Select the snippet, and it will be inserted directly into your document at your cursor's position.

## Template Scopes

Templates are organized by scope to help manage who can see and use them:
*   **System**: Built-in templates available to everyone on the server.
*   **Team**: Templates created for a specific team, available only to members of that team.
*   **Personal**: Private templates available only to the user who created them.

## Placeholders

Templates can include **Placeholder Blocks**—instructional text (e.g., "Type meeting attendees here...") that guides the user on what to enter. As soon as you click into a placeholder and start typing, it transforms into standard text.
