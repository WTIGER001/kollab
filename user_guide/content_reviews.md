# Reviewing Page Content

Use the **Content Review** block to show whether a page is still a draft, being reviewed, approved, or due for another review.

## Add a review block

1. Edit the page and open the macro picker.
2. Choose **Content Review** from the Layout category.
3. Choose a status and, if the page needs regular upkeep, set **Next review**.

Anyone who can edit the page can update its review state. Readers can see the current state and review date but cannot change it.

An approved page automatically displays as **Stale** after its next-review date passes. Kollab does not yet send reminder notifications for overdue reviews.

## Publish a reviewed page

Publishing saves the current page as the reader-safe version. Later edits remain in the draft until you publish again, so readers using the published page do not see unfinished changes.

Use the page's **Publish** action when the content is ready. The published snapshot is retained in version history and can be safely replaced by a newer publication.
