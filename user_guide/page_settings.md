# Page Settings & Custom URLs

Kollab automatically generates clean, human-readable URLs for every page you create based on the page's title. This helps keep links friendly and easy to share.

However, there may be times when you want to create a short alias (e.g. `/teams/dev/onboarding`) or fix a typo in the URL.

## Changing a Page URL

1. Open the document you wish to edit.
2. In the top right corner of the editor header, click the **More Options** (`...`) button.
3. Select **Page Settings** from the dropdown menu.
4. In the Page URL Slug field, type your custom alias. Note: the system will automatically format your input to use lowercase letters and hyphens.
5. A live indicator will verify if the URL is available. If the URL is already used by another document, you will need to choose a different one.
6. Click **Save Changes**.

## URL Aliases (Redirects)

When you change a page's URL slug, Kollab automatically remembers the previous URL. 
If anyone visits the old URL (e.g. from an old email link, Slack message, or bookmark), they will be automatically redirected to the new, correct URL without encountering a broken link page!
