# Basic Formatting

The Kollab Editor provides a robust set of basic text formatting tools to help you structure and stylize your content effectively.

## Formatting Options
You can access all basic formatting options via the **Editor Toolbar** docked at the top of your page.

- **Bold (`Cmd/Ctrl + B`)**: Emphasize important text.
- **Italic (`Cmd/Ctrl + I`)**: Italicize text for citations or subtle emphasis.
- **Strikethrough (`Cmd/Ctrl + Shift + S`)**: Cross out text that is no longer relevant.
- **Underline (`Cmd/Ctrl + U`)**: Underline text for emphasis or document styling.
- **Highlight (`Cmd/Ctrl + Shift + H`)**: Apply a vibrant background highlight to make text stand out.
- **Text Color**: Use the palette icon to apply a custom color to the selected text.
- **Subscript & Superscript**: Ideal for mathematical equations or citations.

## Inserting Links
You can insert hyperlinks to external websites or directly to other internal Kollab Pages. 

### How to Insert a Link
1. Highlight the text you want to hyperlink.
2. Click the **Link** icon in the toolbar, or press `Cmd/Ctrl + K`.
3. The **Insert Link Dialog** will open with two tabs:
   - **Search**: Start typing to find another Page within your current Project or Team.
   - **Web Link**: Manually type or paste an external URL (e.g., `https://google.com`).
4. (Optional) You can update the **Link Text to Display** directly from this dialog.
5. Click **Insert** to apply the link.

### Editing or Removing Links
Once a link is inserted, clicking on it will reveal a small floating menu:
- Click the **Edit** icon (pencil) to change the destination URL or display text.
- Click the **Unlink** icon (broken chain) to remove the hyperlink while keeping the text intact.
- Click the **External Link** to open the destination in a new browser tab.
