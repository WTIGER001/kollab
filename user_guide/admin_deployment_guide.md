# Administration and Deployment

> **Availability: reference only.**

The repository does not currently include the Kubernetes manifests, Azure infrastructure, or GitOps configuration described by the proposed deployment architecture. Do not treat those examples as an executable production deployment guide.

For local development, use the repository's main README and configure OIDC according to the [OIDC guide](oidc_sso.md). A production deployment guide will be added with tested infrastructure assets.
